# Tripleten web_project_around_express

Projeto desenvolvido para praticar a criação de uma API REST com **Node.js** e **Express**, utilizando arquivos JSON como fonte temporária de dados.

## Tecnologias

- Node.js
- Express
- Nodemon
- ESLint (Airbnb)

## Como executar

```bash
npm run start
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Rotas

- `GET /users` — Lista todos os usuários.
- `GET /users/:id` — Retorna um usuário pelo ID.
- `GET /cards` — Lista todos os cards.
