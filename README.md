# Tripleten | Web Project Around

Aplicação web interativa para gerenciamento de cartões de lugares.

## Sobre o projeto

Aplicação interativa que permite que usuários criem e gerenciem cartões com imagens de lugares, editem seu perfil e interajam com cartões por meio de curtidas.

## Tecnologias

### Frontend

React
JavaScript
Vite
CSS

### Backend

Node.js
Express
MongoDB
Mongoose
JWT
Celebrate/Joi
Winston

## Funcionalidades

- cadastro e login
- autenticação por JWT
- edição de perfil
- alteração de avatar
- criação de cartões
- exclusão de cartões próprios
- curtidas
- visualização ampliada das imagens
- validação de formulários
- tratamento centralizado de erros

## Estrutura do projeto

web_project_api_full/
├── backend/
└── frontend/

## Instalação e execução

cd backend
npm install
npm run start

cd frontend
npm install
npm run dev
