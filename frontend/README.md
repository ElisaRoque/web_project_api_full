# Around The U.S.

Aplicação web desenvolvida em React que permite explorar cartões de locais dos Estados Unidos, criar novos cartões, curtir e excluir cartões e editar informações do perfil.

## Sobre o projeto

O **Around The U.S.** é uma aplicação desenvolvida como parte do projeto de formação em desenvolvimento web da TripleTen.

Nesta etapa, a aplicação foi integrada a uma API externa e passou a contar com **registro e autenticação de usuários**, incluindo armazenamento do token de autenticação no `localStorage` e proteção das rotas que exigem login.

## Funcionalidades

- Cadastro de novos usuários
- Login e autenticação por JWT
- Persistência da sessão utilizando `localStorage`
- Exibição das informações do usuário
- Edição do perfil
- Atualização da foto de perfil
- Criação de novos cartões
- Exclusão de cartões
- Curtidas nos cartões
- Visualização das imagens em popup

## Tecnologias utilizadas

- React
- Vite
- HTML5
- CSS3
- REST API
- JWT
- LocalStorage

## Execução do projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```
